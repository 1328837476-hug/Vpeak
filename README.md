# Vpeak

和熟悉的 AI 伙伴，把英语慢慢说出来。

Vpeak 是一个正在开发的英语语音陪练项目，希望把自然交流、长期伙伴设定和有据可查的学习反馈连接起来。

## 当前状态

本仓库已初始化项目说明与 MIT 许可证，正在整理首个公开源码版本。完整应用源码和安装包尚未发布到此仓库。

当前本地实现采用 Flutter 移动端与 Python / FastAPI 后端，围绕以下方向迭代：

- 伙伴创建、编辑，以及相处与学习偏好。
- 语音交流、中文帮助、短练习与会后回顾。
- 用户可查看、修改和删除的关系记忆与学习记录。
- 自有对话模型接入及明确的数据去向。

真实语音体验、发音评估效果和跨设备稳定性仍在验证中。
